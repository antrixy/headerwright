Initiator oracle

This page exists to answer one question that test/oracle/ cannot: does a HeaderWright profile scoped to the target apply to a request made by a page on a different site?

Colour does not encode pass or fail here either. Whether an absent header is the right answer depends entirely on which grants are held, and this page does not know that — Chrome does not tell it. Red marks one thing only: the measurement did not happen. Read the row against the prediction you registered in the runbook before you opened Chrome.

This page is loaded from __THIS_HOST__. It will fetch __TARGET_ORIGIN__/echo.

How to read it

  • Cross-origin row — open this page on __INITIATOR_ORIGIN__. The fetch crosses to the target. If only the target is granted, HW-V6-01 predicts the profile's header is absent.
  • Same-origin control — open this page on __TARGET_ORIGIN__. Initiator and target are the same host, so the one grant covers both and the header should be present. This control is what separates “the initiator grant is missing” from “HeaderWright is not applying anything at all”. A cross-origin absence means nothing without it.
