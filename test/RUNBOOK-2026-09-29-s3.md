## What AR-02 claims, and how each row can fail

s3 (S3-D1–D5) makes a draft carry the digest of the profile version it was
written against, and use it:

- **S, a stale draft.** A restored draft binds the editor to its own base.
  If the profile changed since, Save refuses it as `changed` with nothing
  written, through s2's refusal (no new copy). Revert to saved loads the
  current version, drops the draft, and reopens the draft session.
- **I, Replace.** After the profile write, a draft survives only if the file
  holds its profile unchanged (same id, digest equal to the draft's base).
- **D, Delete.** A confirmed Delete drops that profile's draft, and only that
  one. A new profile that reuses the id shows no marker.
- **E, enum.** A draft with a row outside the validator's side or operation
  set is refused whole: no card marker, and Edit opens the saved profile.

The other writer is the popup's own DevTools console, as in Sitting J. It
writes `hw:profiles` in `chrome.storage.local` (Row S), or `hw:drafts` in
`chrome.storage.session` (Row E). The popup re-renders its list when
`hw:profiles` changes, never when `hw:drafts` does, so every draft that
must show on a card is followed by a reopen.

| name | what it is |
| --- | --- |
| PRE | v0.2.2 (`2ee97ae`, published): drafts v1 with no base; a restored draft binds to the profile stored when Edit opens; no purge on Delete; no re-check on Replace; any string side or operation accepted |
| M-livebase | a restored draft binds to the profile as stored when Edit opens (the s2 gap; s3 mutants M10, M29) |
| M-noreopen | Revert to saved does not reopen the draft session (M35) |
| M-keepall | Replace re-checks no draft (M38) |
| M-dropall | Replace drops every profile draft (S3-D3's rejected alternative) |
| M-nopurge | Delete does not purge (M36) |
| M-purgeall | Delete drops every draft |
| M-noenum | a row outside the validator's sets is accepted (M5) |

Row S fails on PRE, M-livebase and M-noreopen. Row I fails on PRE, M-keepall
and M-dropall. Row D fails on PRE, M-nopurge and M-purgeall. Row E fails on
PRE and M-noenum.

**Not tested here, and stated in FINDING-048:** keystrokes typed while a Save
is writing are not kept; a draft orphaned by a delete made outside the popup
is not purged; the popup can close between a profile write and its draft
cleanup. The popup wiring stays guarded by scans and mutants.
