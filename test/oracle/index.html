HeaderWright response-header oracle

Same-origin by construction. The sent-side record arrives in a response body via /sent, which modifyHeaders cannot rewrite; the received side is read from Response.headers. A difference between them is DNR acting on the response.

Before trusting anything on this page, run node selfcheck.mjs against this server. It proves the comparison can report a difference at all. A page that shows “unmodified” is only meaningful if the instrument has been shown capable of showing “modified”.

Blind spot: Set-Cookie is stripped from Response.headers by the Fetch spec even same-origin. An empty diff for it means not observed, never unmodified.
